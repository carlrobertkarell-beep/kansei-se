VANLIGA FRÅGOR

Innan du kontaktar oss.

Behöver jag remiss?

Nej. Du bokar direkt utan remiss.

Kan ni hjälpa mig välja rätt besök?

Ja. Använd bokningshjälpen. Den guidar till ett rimligt första steg utan att försöka ställa diagnos online.

Öppna bokningshjälpen →

Hur begär jag ut min journal?

Mejla info@kansei.se så hjälper vi dig vidare med en säker hantering.

Vad gäller vid sen avbokning?

Av- och omboka via din bokningsbekräftelse. Vid sen avbokning eller uteblivet besök kan besöket debiteras.

När ska jag inte vänta på svar från Kansei?

Vid akuta eller snabbt försämrade symtom ska du kontakta sjukvården. Ring 1177 för vägledning och 112 vid livshotande tillstånd.
