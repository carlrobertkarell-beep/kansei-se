Ultraljud vid misstänkt skada på hälsenan

Vid en skada på Achillessenan kan ultraljud användas för att bedöma senkontinuitet, fokala defekter och omgivande vävnad, ofta även dynamiskt.

Undersökningen utförs av Carl-Robert Kårell, legitimerad naprapat med utbildning inom muskuloskeletalt ultraljud, på Upplandsgatan 26 vid Odenplan i Stockholm.

VAD ULTRALJUDET KAN BIDRA MED

Riktad undersökning av rätt struktur.

Vid en skada på Achillessenan kan ultraljud användas för att bedöma senkontinuitet, fokala defekter och omgivande vävnad, ofta även dynamiskt.

Undersökningen styrs av anamnes, smärtlokalisation och kliniska fynd. Vid behov används jämförelse med motsatt sida eller dynamisk undersökning.

VIKTIG AVGRÄNSNING

Fyndet måste passa helheten.

Vid akut misstanke om total hälseneruptur ska klinisk bedömning ske skyndsamt. Ultraljud får inte fördröja relevant ortopedisk handläggning.

NÄSTA STEG

Från bild till beslut.

Relevanta fynd förklaras och dokumenteras. Nästa steg kan vara rehab, behandling, anpassad belastning eller vidare medicinsk utredning beroende på helhetsbedömningen.
