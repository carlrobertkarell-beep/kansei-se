Om ultraljud →

Senor, slemsäck och nerv vid armbågen

Ultraljud kan ge information om senfästena på armbågens utsida och insida, bicepssenans nedre fäste och tricepssenan på baksidan. Vid rätt frågeställning undersöks också en ytlig slemsäck eller ulnarisnerven.

När kan bilderna tillföra något?

Det kan vara vid långvarig belastningssmärta, lokal svullnad eller misstanke om en senskada. Många armbågsbesvär går att bedöma kliniskt. Vi börjar därför med vad du har svårt att göra och vilken fråga ultraljudet kan besvara.

Så går undersökningen till

Du berättar vilka rörelser som gör ont och om besvären började efter en särskild händelse. Vi undersöker rörelse, ömhet och funktion. Därefter sitter eller ligger du med armen stödd medan givaren förs över huden med gel.

Du får ibland böja, sträcka eller vrida armen för att olika delar ska bli synliga. Fynden förklaras vid besöket och dokumenteras skriftligt. Du får råd om belastning, rehabilitering eller vidare utredning.

Ta gärna en kortärmad tröja och tidigare bildutlåtanden.

Vad kan ultraljud inte avgöra?

Ett senfynd är inte alltid orsaken till smärtan. Nervens utseende visar inte hela nervfunktionen; neurografi kan behövas som komplement. Vid frågor om skelett eller djupa delar av leden kan annan bilddiagnostik vara mer relevant.

OMRÅDEN VI KAN UNDERSÖKA

Det här tittar vi närmare på

Undersökningen anpassas efter dina besvär. Här är exempel på strukturer och frågor som kan vara aktuella.

Senfästet på utsidan – tennisarmbåge

Här fäster flera muskler som sträcker handleden. Vi bedömer synliga förändringar i senan och dess fäste. Läs mer om ultraljud vid tennisarmbåge.

Senfästet på insidan – golfarmbåge

Senfästet för flera böjmuskler kan undersökas när smärtan sitter på insidan. Bilderna jämförs med ömhet och besvär vid belastning.

Bicepssenan framtill

Bicepssenan följs mot sitt fäste nära armbågen vid misstänkt senskada. Senans djup och läge kan begränsa bedömningen. Se distala bicepssenan.

Triceps och slemsäcken på baksidan

Vi kan undersöka tricepssenans fäste och den ytliga slemsäcken vid armbågsspetsen när området gör ont eller är svullet.

Ulnarisnerven på insidan

Nervens utseende och rörelse kan följas vid böjning och sträckning. Läs om ultraljud av ulnarisnerven.

Vanliga frågor om undersökningen

Kan ultraljud visa tennisarmbåge?

Det kan visa förändringar i senfästet på armbågens utsida. Diagnosen bygger också på symtom och kliniska tester; alla med tennisarmbåge behöver inte ultraljud.

Kan domningar från armbågen undersökas?

Ulnarisnerven kan bedömas anatomiskt och under rörelse. Vid frågor om nervens signalöverföring kan neurografi behövas.

Får jag ett utlåtande?

Ja. Du får en genomgång av fynden och en skriftlig bedömning, samt råd om nästa steg.
