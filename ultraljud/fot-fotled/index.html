VAD VI KAN BEDÖMA

Strukturer i fot & fotled

Achillessena, plantarfascia, peroneus- och tibialissenor, extensorsenor, ytliga ligament och andra mjukdelar kring fotleden.

NÄR DET KAN VARA RELEVANT

Frågeställningen styr

Hälsmärta, Achillesbesvär, plantarfasciabesvär, senrelaterad smärta eller kvarstående besvär efter fotledsstukning.

UNDERSÖKNINGEN

Så går det till

Vi börjar med anamnes och riktad klinisk undersökning. Därefter undersöks relevanta strukturer systematiskt med ultraljud. Vid behov används dynamisk undersökning och jämförelse med motsatt sida. Fynden förklaras i rummet och dokumenteras skriftligt.

VIKTIGT

Ultraljud har gränser.

Dynamisk undersökning kan vara särskilt användbar för senor kring fotleden. Misstänkta frakturer, osteokondrala skador och djupare ledstrukturer kräver ofta annan bilddiagnostik.

Ett bildfynd är inte automatiskt förklaringen till smärtan. Bedömningen görs utifrån helheten.

STRUKTUR FÖR STRUKTUR

Det här tittar vi närmare på

Fot och fotled innehåller många ytliga senor och ligament som lämpar sig för dynamisk högfrekvent ultraljudsundersökning.

Achillessena

Achillessenan bedöms längs sitt förlopp och vid infästningen avseende struktur, tjocklek, fokala defekter och entesnära förändringar.

Plantarfascia

Proximala plantarfascians tjocklek och struktur kan bedömas vid plantar hälsmärta. Bildfynd måste korreleras med den kliniska bilden.

Peroneussenor

Peroneus longus och brevis kan följas bakom laterala malleolen. Dynamisk undersökning kan användas vid frågeställning om instabilitet eller subluxation.

Tibialis posterior och mediala senor

Tibialis posterior samt andra tillgängliga flexorsenor kan bedömas vid medial fotleds- och fotsmärta.

Laterala ligament

ATFL och vissa andra ytliga ligamentkomponenter kan bedömas efter fotledsdistorsion. Ultraljudet ersätter inte fullständig utredning vid misstänkt fraktur eller osteokondral skada.

Framfot och lokala mjukdelar

Riktade frågeställningar i framfoten kan ibland bedömas med ultraljud, exempelvis vissa mjukdelsförändringar. Skelettsmärta eller stresskademisstanke kan kräva annan bilddiagnostik.
