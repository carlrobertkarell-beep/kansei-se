Svullet knä – vad kan ultraljud visa?

Vid ett svullet knä kan ultraljud användas för att bedöma ledvätska, suprapatellära recessen, bursae och cystiska förändringar som Bakercysta. Undersökningen kombineras med klinisk bedömning.

Undersökningen utförs av Carl-Robert Kårell, legitimerad naprapat med utbildning inom muskuloskeletalt ultraljud, på Upplandsgatan 26 vid Odenplan i Stockholm.

VAD UNDERSÖKNINGEN KAN BIDRA MED

En riktad bildbedömning.

Vid ett svullet knä kan ultraljud användas för att bedöma ledvätska, suprapatellära recessen, bursae och cystiska förändringar som Bakercysta. Undersökningen kombineras med klinisk bedömning.

Vi jämför fynden med din anamnes, palpation, rörelse och relevanta kliniska tester. Vid behov jämförs med motsatt sida eller används dynamisk undersökning.

VIKTIG AVGRÄNSNING

Bildfynd är inte hela diagnosen.

Ultraljud kan visa och lokalisera vätska men säger inte ensamt varför knät är svullet. Trauma, infektion, inflammatorisk ledsjukdom och andra orsaker kan kräva annan medicinsk utredning.

EFTER UNDERSÖKNINGEN

Du ska veta vad nästa steg är.

Relevanta fynd förklaras direkt och dokumenteras. Beroende på helhetsbedömningen kan nästa steg vara rehabilitering, fortsatt behandling, avlastning eller vidare medicinsk utredning.
